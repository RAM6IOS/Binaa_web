# تقرير اختبار الكتابة المحدودة — منصة Binaa

**التاريخ:** 2026-08-06
**الهدف:** Production — مشروع واحد ثابت لكل حساب اختباري (`projectIds[0]`)
**الأداة:** k6 v2.1.0 — ملفات: `scripts/k6/{write-smoke,write-load}.js` + `lib/write-journeys.js`
**الوضع:** كتابة محدودة — إنشاء مهمة `[LOADTEST]` + قراءة تأكيدية. **لا service_role**، لا حذف ضمن الاختبار، لا تعديل بيانات عملاء.

---

## النتائج

| المقياس | write-smoke | write-load | الهدف |
|---|---|---|---|
| الإعداد | 5 VUs • 3د • 1 إنشاء/ث | 12 VUs • 4د • 3 إنشاء/ث | ≤15 VU • 3–5د |
| عمليات الإنشاء | 180 | 721 | — |
| نجاح الإنشاء (201) | 180/180 | 721/721 | — |
| نجاح القراءة المؤكدة (200) | 180/180 | 721/721 | — |
| **p95 للإنشاء** | **208ms** | **159ms** | <3s ✓ |
| p95 للقراءة | 155ms | 129ms | <3s ✓ |
| فشل الكتابة | 0% | 0% | <5% ✓ |
| أخطاء RLS / 4xx / 5xx | 0 | 0 | 0 |

**المجموع:** 901 مهمة `[LOADTEST]` أُنشئت + 901 قراءة تأكيدية، كلها ناجحة.

## الضوابط المطبقة
- الوسم `[LOADTEST]` في العنوان والوصف والملاحظات لكل صف.
- الكتابة على أول مشروع فقط لكل حساب (أصغر أثر).
- جلسات عبر كلمات مرور حقيقية + anon key فقط.

## اكتشاف — `created_by` = null في جدول tasks
كل المهام المدرجة أظهرت `created_by = null` (لا default ولا trigger يملؤه). RLS على المهام يعمل عبر ملكية المشروع لا المنشئ. **توصية:** إضافة default `auth.uid()` لعمود `created_by` لتتبّع المنشئ.

## تنظيف البيانات
أُنشئ `scripts/k6/cleanup-loadtest.mjs` لحذف المهام ذات `title LIKE *LOADTEST*` على مشاريع الحسابين فقط، بحسابيهما عبر RLS. العدد قبل الحذف: 901 (بقي 900 بعد حذف صف اختباري واحد يدوياً أثناء التحقق).
